# Research Best Debugging Techniques for React

## What are the most common debugging techniques?

Console in web browser, react devtools and vscode/IDE debugger

## Which tools are most effective for React debugging?

It depends on different scenes, if you want to check props value and does it update using react devtools
If you want to figure out what problem in your code, maybe logic is wrong, can use IDE debugger.

## How do you debug issues in large React codebases?

Check the console log inbrowser first, if it is running. if not I will using IDE debugger.
If you want to improve performance or check props, just using react devtools in browser.
