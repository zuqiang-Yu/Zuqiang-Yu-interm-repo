# VS Code Shortcuts (Mac)

**Setup:** I installed VS Code on my MacBook Air (macOS) and practised each of these shortcuts while working on my React Native onboarding project.

The following are the shortcuts I use most often.

## Navigation

- `Cmd + P` - Quick Open: search for and open any file by name
- `Cmd + Shift + P` - Command Palette: search for and run any VS Code command
- `Ctrl + G` - Go to a specific line number
- `Cmd + F` - Search within the current file
- `Cmd + Shift + F` - Search across all files in the project

## Editing

- `Option + Click` - Add a cursor at each click position (multiple cursors)
- `Cmd + Shift + K` - Delete the current line

## Debugging

- `F5` - Start or continue debugging

## Terminal

- `Cmd + \` - Split the terminal into two panes (when the terminal is focused)
- `Cmd + K` - Clear the terminal

## The Most Useful Shortcuts in My Daily Work

These are the shortcuts I think I will use most.

The first is `Cmd + F` to search within the current file. When I see a
method name in an error message, I open the file and use `Cmd + F` to
search for that keyword and find it immediately, instead of scrolling
through hundreds of lines manually.

The second is `Option + Click` to add multiple cursors. When I need to
rename a variable or update the same value in several places at once, I
click each location and edit them all at the same time.

The third is `Cmd + P` to quickly open any file by name. Instead of
clicking through the file tree, I just type part of the filename and
jump straight to it.

## How Can Keyboard Shortcuts Improve Your Productivity?

Keyboard shortcuts let me use built-in features instantly without
searching through menus. For example, finding text in a file without a
shortcut means opening the menu and clicking Find, whereas `Cmd + F`
does the same thing in under a second.

Shortcuts also reduce how often I need to switch between the keyboard and
the mouse. While coding, reaching for the mouse breaks my focus and
interrupts my train of thought. Actions like jumping to a file with
`Cmd + P` or searching by keyword with `Cmd + F` each save only a few
seconds, but repeated dozens of times a day, the time saved adds up.
