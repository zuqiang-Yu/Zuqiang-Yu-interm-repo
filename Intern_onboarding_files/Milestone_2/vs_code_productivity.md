# VS Code Shortcuts (Mac)
 Below shortcuts I usually used in work
## Navigation
 
| Shortcut | Action |
|---|---|
| `⌘ + P` | Quick open — search and open any file by name |
| `⌘ + Shift + P` | Command Palette — search and run any VS Code command |
| `⌘ + G` | Go to a specific line number |
| `⌘ + F` | Search within the current file |
| `⌘ + Shift + F` | Search across all files in the project |
 
## Editing
 
| Shortcut | Action |
|---|---|
| `⌥ + Click` | Add multiple cursors at each click position |
| `⌘ + Shift + K` | Delete the entire current line |
 
## Debugging
 
| Shortcut | Action |
|---|---|
| `F5` | Start / continue debugging |
| `F10` | Step over — execute the next line without going into the function |
| `F11` | Step into — go inside the function call |
 
## Terminal
 
| Shortcut | Action |
|---|---|
| `` ⌃ + ` `` | Open / close the integrated terminal |
| `⌘ + Shift + 5` | Split the terminal into two panes |
| `⌘ + K` | Clear the terminal |

# How can keyboard shortcuts improve your productivity?
Keyboard shortcuts allow you to access built-in features instantly without having to search for them. 
For example, to search within a file, a user without shortcuts would need to locate the option in the menu and click it — whereas pressing ⌘ + F does the same thing in under a second. 

Shortcuts also reduce how often you need to switch between the keyboard and mouse, which matters during coding because reaching for the mouse breaks your focus and interrupts your train of thought. Actions like jumping to a file with ⌘ + P or searching by keyword with ⌘ + F each save only a few seconds, but repeated dozens or hundreds of times throughout a day, the time saved becomes significant.
