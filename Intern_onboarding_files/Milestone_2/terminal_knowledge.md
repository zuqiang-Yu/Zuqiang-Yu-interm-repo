# Basic Terminal Usage

## Which terminal client did you choose? Why?

I chose the **Mac built-in Terminal**. It comes pre-installed, launches immediately, and covers everything I need at this stage of the internship — running git commands, navigating the file system, and executing scripts. There is no setup overhead, which means I can get straight to work without spending time configuring a third-party tool.

I am aware of iTerm2 and plan to try it at some point to see whether features like split panes or better colour rendering make a meaningful difference to my workflow. For now, the built-in Terminal is familiar, stable, and sufficient for my current tasks. If iTerm2 offers a clear productivity advantage once I have more context on the codebase and day-to-day workflow, I will switch then.

---

## What customisations (if any) did you make?

I kept the setup minimal and practical. I adjusted the Terminal font size to something more readable during long sessions, and set the colour scheme to the built-in **Pro** theme (dark background, light text) to reduce eye strain — especially useful on Friday afternoons at Sandringham Library where the lighting can be variable.
